# Real-Time Diagnostics & Telemetry UI Flow

Screenshots validating low-level system performance metrics and memory constraints for hackathon judges:

- `01_diagnostics_overview.png`: Real-time system monitor showing STT/TTS inference status, active memory consumption (<250MB enforcement), and CPU utilization.
- `02_diagnostics_latency_rtf.png`: Measured Real-Time Factor (RTF) gauge, end-to-end transceiver delay graph, and silence endpointer duration.
- `03_diagnostics_radio_link.png`: Wi-Fi Direct / BLE packet stats, byte throughput (<100B/transmission), retransmission count, and AES-GCM verification rate.
- `04_diagnostics_audio_focus.png`: Audio focus state machine, volume lock override status, and microphone sampling health (16kHz 16-bit PCM).
