# Radar & P2P Discovery UI Flow

Screenshots showcasing offline peer discovery and mesh connectivity:

- `01_radar_scanning.png`: Circular radar pulse scanning for nearby Wi-Fi Direct and Bluetooth Low Energy devices without router or cellular network.
- `02_radar_peers_found.png`: Discovered peer devices displayed as radar blips with estimated distance/RSSI and profile avatars.
- `03_radar_pairing_prompt.png`: Mutual security handshake prompt for AES-256 session establishment and profile exchange (Packet 0x0A).
- `04_radar_connected.png`: Active peer session with channel status, signal quality, and direct PTT link.
